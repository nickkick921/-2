ARCHI LAB 처음 사용하기
1. 예시 도면 열기

상단의 ‘예시 도면’을 눌러 거실·주방·침실이 있는 샘플을 불러오세요. 새로 시작하려면 ‘새 도면’을 누르세요.

2. 도구 고르기

왼쪽 도구를 선택하세요. 벽·공간·문·창문은 드래그하고, 기둥·계단·가구는 도면을 한 번 클릭해 배치합니다.

3. 크기와 위치 수정

‘선택’ 도구로 객체를 선택하면 오른쪽에 속성이 나타납니다. 숫자를 바꾸어 정확한 치수로 조정할 수 있습니다.

4. 실수 되돌리기

왼쪽 실행 취소·다시 실행을 쓰거나 Ctrl+Z / Ctrl+Y를 누르세요. Delete 키로 선택한 객체를 지울 수 있습니다.

5. 3D와 재료 살펴보기

위쪽 ‘3D 미리 보기’를 누르고, 오른쪽 ‘3D 외관·재료 설정’에서 벽·바닥·지붕 재료를 바꾸어 보세요.

6. 층별 설계와 분석

캔버스 위 ‘설계 층’에서 1~3층 도면을 따로 작성할 수 있습니다. 일조 분석과 구조 실험은 학습용 계산입니다. JSON 프로젝트로 모든 층을 함께 저장하세요.

추천 학습 순서: 예시 도면 열기 → 선택·이동 연습 → 벽과 방 추가 → 문·창문·계단 배치 → 3D 보기 → 분석 기능 체험 → 프로젝트 저장.
