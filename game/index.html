새 게임을 추가하는 방법

새 게임 HTML 파일을 이 랜딩페이지와 같은 폴더에 저장한 다음, 오른쪽 예시처럼 GAMES 목록에 게임 정보를 한 항목 추가하면 됩니다.

1새 게임 파일을 같은 폴더에 저장합니다.
2아래 코드 항목을 복사해 GAMES 배열 안에 붙여 넣습니다.
3게임 제목과 파일명을 바꾸고 저장하면 카드가 자동으로 나타납니다.

  title: "새로운 게임",

  icon: "🎮",
